# jjwxc_dl

[English](README.md) · **Русский** · [简体中文](README.zh-CN.md)

Докачиваемый загрузчик, который сохраняет главы с JJWXC (晋江文学城), доступные
вашему аккаунту, в EPUB. Построен на Playwright.

Переработка [tracywong117/jjwxc-downloader](https://github.com/tracywong117/jjwxc-downloader)
(MIT). Что именно изменилось и почему — в разделе [Благодарности](#благодарности).

## Что он делает и чего не делает

Читает главы, **которые ваш аккаунт уже может открыть**, и собирает из них EPUB
с обложкой и оглавлением.

- Бесплатные главы не требуют аккаунта вообще.
- Для VIP-глав нужно быть залогиненным **и владеть покупкой**. Вход происходит
  в настоящем браузере, который вы открываете и заполняете сами; ваш пароль
  инструмент не видит и не хранит.
- Главы, которые вы не покупали, помечаются как `paywalled`, попадают в отчёт
  и в EPUB не включаются. Заглушками они не заполняются.
- В платных главах часть текста спрятана за подменным шрифтом. Инструмент её
  восстанавливает и отчитывается за каждый возвращённый символ — см.
  [Подменный шрифт](#подменный-шрифт).

Это не обход пейвола, и никаких технических средств защиты инструмент не
трогает. Хотите книгу — купите её: команда `fetch` печатает стоимость
VIP-части конкретного романа заранее.

> **Готовые файлы держите при себе.** JJWXC встраивает в текст VIP-глав
> водяные знаки, привязанные к купившему аккаунту. Файл, которым вы
> поделитесь, указывает на вас.

## Требования

Python 3.9+ и система, куда Playwright сможет поставить Chromium. Проверено на
Python 3.14 / Windows 11 и Python 3.10.

```bash
pip install -r requirements.txt
```

```bash
python -m playwright install chromium
```

## Использование

`novelid` виден в адресе страницы романа:
`jjwxc.net/onebook.php?novelid=`**`1234567`**.

### 1. Скачивание

```bash
python jjwxc_dl.py fetch 1234567
```

```
某本书 - 某作者
305 chapters: 21 free (65,284 chars), 284 VIP (1,071,596 chars)
VIP portion costs roughly 5358 coins (~53.6 CNY) at the standard 5 fen/1k rate
305 chapters to fetch

[1/305] 第一章 (free) ... ok, 3021 chars
[22/305] 第二十二章 (VIP) ... paywalled
```

Каждая глава сохраняется в отдельный JSON-чекпойнт, поэтому Ctrl+C безопасен:
повторный запуск той же команды пропускает уже полученное и повторяет только
то, что не удалось.

### 2. Вход в аккаунт (разово, для VIP-глав)

```bash
python jjwxc_dl.py login
```

Откроется браузер на jjwxc.net. Залогиньтесь сами, затем нажмите Enter в
консоли. Сессия останется в `.jjwxc-profile/` рядом со скриптом и будет
переиспользована последующими запусками `fetch`. Не запускайте две копии
инструмента на одном профиле — Chromium блокирует его под один процесс.

### 3. Сборка таблицы шрифта

```bash
python jjwxc_dl.py fontmap 1234567
```

Опознаёт символы, которые платные главы прячут за подменным шрифтом — см.
[Подменный шрифт](#подменный-шрифт). Запускается один раз на книгу, после того
как `fetch` соберёт шрифты глав. Занимает несколько минут и пишет
`downloads/<novelid>/fontmap.json`.

Всё, в чём команда не уверена, выводится списком с альтернативами. Неверное
решение правится в поле `char` соответствующей записи, после чего достаточно
заново запустить `build` — перекачивать ничего не нужно.

### 4. Сборка EPUB

```bash
python jjwxc_dl.py build 1234567
```

Пишет `downloads/<novelid>/<название>.epub`, перечисляет главы, которых в нём
нет, и отчитывается по каждой сделанной подстановке.

### Параметры

| Флаг | По умолчанию | Примечание |
| --- | --- | --- |
| `--delay` | `2.0` | Базовая пауза между главами; фактическая — от `delay` до `2×delay`. |
| `--timeout` | `20.0` | Таймаут на страницу, в секундах. Поднимите на медленном канале. |
| `--retries` | `3` | Попыток на главу, с наращиванием паузы. |
| `--headless` | выкл. | Скрыть браузер. На первом запуске лучше оставить выключенным. |
| `--out` | `downloads` | Куда складывать чекпойнты и EPUB. |
| `--profile` | `.jjwxc-profile` | Профиль браузера с вашей сессией. |

**Не занижайте `--delay`.** Триста с лишним запросов подряд на полной скорости —
самый быстрый способ получить ограничение по частоте, и это невежливо по
отношению к сайту, которому вы платите.

## Подменный шрифт

Платные главы отдаются не обычным текстом. К каждой прилагается собственный
веб-шрифт (`jjwxcfont_*`), а часть текста заменена на символы из частной
области Юникода, причём каждая подменённая позиция помечена ещё и невидимым
символом нулевой ширины. В браузере всё читается, потому что глиф шрифта для
`U+Ennn` рисует настоящий иероглиф; сохраните текст — и на их месте останутся
дыры. В книге, на которой всё это отлаживалось, таких символов оказалось
45 496 — **3,5 % текста**, во всех платных главах, примерно дыра на каждое
второе-третье предложение. Бесплатные главы не затронуты.

Восстановить это позволяют два обстоятельства:

- Устойчивая примета — **контур глифа**. Имена внутри шрифта кодируют PUA-код,
  а не иероглиф, и контуры перегенерированы через `svg2ttf`, так что ни с одним
  базовым шрифтом побайтно не совпадают. Но все шрифты глав определяют *одни и
  те же 200 контуров* и лишь тасуют, какой код на какой указывает. В той книге
  было 93 разных шрифта на 305 глав — и все на этих же 200 формах.
- Значит, 200 форм опознаются **один раз**, а дальше каждая глава
  расшифровывается простым поиском.

Опознание опирается на два независимых сигнала, потому что начертанию одному
доверять нельзя. Растеризация глифа и сравнение с кандидатами в трёх эталонных
шрифтах решает большинство случаев, но систематически предпочитает редкие
иероглифы тем частым, на которые они похожи: выбирались 冇 вместо 有, 犬 вместо
大, 已 вместо 己 — с разрывом в тысячные доли. Поэтому каждый кандидат ещё и
подставляется в те места, где глиф реально встречается, а получившиеся би- и
триграммы взвешиваются по чистому тексту той же книги. На той книге корпус
переопределил решение по начертанию **25 раз из 199** — это около 5500
символов, которые иначе молча ушли бы в текст неверными.

Решение, за которым стоит только начертание, помечается как `unverified`, каким
бы большим ни был разрыв, и `build` сообщает, сколько подстановок пришло из
таких записей. Дыра лучше правдоподобного неверного иероглифа, поэтому
нерешённые позиции не угадываются, а остаются на месте и попадают в отчёт.

Это восстановление отрисовки, а не доступа. Главы, которых вы не покупали, не
скачиваются в принципе — они в любом случае возвращаются как `paywalled`, — так
что речь идёт исключительно о том, чтобы сделать машиночитаемым уже оплаченное.

## Структура файлов

```
downloads/<novelid>/
├─ meta.json              название, автор
├─ cover.jpg
├─ fontmap.json           хеш контура -> символ, с уровнем уверенности
├─ <название>.epub
├─ fonts/
│  └─ jjwxcfont_*.woff2   по одному на шрифт главы, хранятся для воспроизводимости
└─ chapters/
   └─ 0001.json           index, title, url, vip, words, font, text, status
```

`status` принимает значения `ok`, `paywalled`, `error`. Текст главы хранится
ровно таким, каким его отдала страница, вместе с PUA-символами; расшифровка
происходит на этапе `build`, поэтому исправленный `fontmap.json` можно
применить, ничего не перекачивая.

## Разбор проблем

**Купленные главы возвращаются как `paywalled`** — сессия не подхватилась.
Перезапустите `login` и убедитесь, что в открывшемся окне вы действительно
залогинены. Проверьте, что `fetch` и `login` используют один и тот же
`--profile`.

**Много `error`** — поднимите `--timeout`, затем `--delay`. Повторный запуск
пробует только неудавшиеся главы.

**Ошибка на всех главах сразу** — скорее всего изменилась вёрстка и селектор
`div.noveltext` больше не подходит. Запустите без `--headless`, посмотрите на
страницу и откройте issue с описанием.

**`UnicodeEncodeError` при печати названий** — не должно происходить,
инструмент принудительно включает UTF-8 на своих потоках. Если всё же
случилось, сообщите вашу ОС и консоль.

**`build` сообщает о нерешённых подстановках** — сначала выполните `fontmap`
или запустите его заново: форму можно опознать только после того, как она
встретится хотя бы в одной главе.

**`fontmap` выдаёт много форм со статусом `unverified`** — ему не хватило
контекста. Проверьте, что в `downloads/<novelid>/fonts/` лежит шрифт для каждой
платной главы; если нет, перезапустите `fetch`. У бесплатных глав шрифта нет, и
это нормально.

**`fontmap` не находит эталонный шрифт** — укажите его через `--ref`, например
`--ref /usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`. Подойдёт любой
шрифт с широким покрытием CJK; при наличии используются три.

**Иероглиф восстановлен неверно** — поправьте поле `char` в его записи в
`fontmap.json` и перезапустите `build`. И заведите issue: таблица одинакова для
всех книг, так что ваша правка пригодится всем.

**В EPUB нет обложки** — обложки отдаёт CDN Sina, который часть запросов
отклоняет. `fetch` печатает причину отказа; повторный запуск пробует снова.

## Благодарности

Переписано с [tracywong117/jjwxc-downloader](https://github.com/tracywong117/jjwxc-downloader),
где заложен сам подход: разбирать страницу оглавления для списка глав, а текст
главы брать из того дочернего элемента `div.noveltext`, в котором больше всего
текста.

Заметные изменения:

- **Playwright вместо Selenium.** Persistent context означает, что логинишься
  один раз и VIP-главы становятся достижимы в принципе; версию
  `chromedriver.exe` подгонять не нужно; локаторы ждут сами.
- **VIP-строки разбираются.** У платных глав нет `href` — адрес лежит в `rel=`
  и ведёт на `my.jjwxc.net`, а клик обрабатывается JS. Поиск только по `href`
  молча пропускает все платные главы книги.
- **Обход строк таблицы вместо `zip()`** двух независимых результатов XPath:
  второй вариант перепутывает названия и адреса, едва списки разойдутся.
- **Возобновляемость.** Чекпойнт на главу в отдельном JSON вместо дописывания
  в один растущий `.txt`, который при повторном запуске дублировал всю книгу.
- **Неоплаченные главы отслеживаются**, а не пишутся в книгу заглушкой.
- **Валидный EPUB.** Текст экранируется перед вставкой в XHTML, поэтому
  случайные `<` или `&` больше не ломают файл. Проставлены метаданные языка.
- **Число знаков по главам** читается из оглавления — отсюда и оценка стоимости.
- UTF-8 принудительно включён на stdout/stderr, чтобы консоль не в UTF-8 не
  обрывала длинную загрузку.
