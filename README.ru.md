# jjwxc_dl

[English](README.md) · **Русский** · [简体中文](README.zh-CN.md)

Докачиваемый загрузчик, который сохраняет главы с JJWXC (晋江文学城), доступные
вашему аккаунту, в EPUB. Построен на Playwright.

Переработка [tracywong117/jjwxc-downloader](https://github.com/tracywong117/jjwxc-downloader)
(MIT). Что именно изменилось и почему — в разделе [Благодарности](#благодарности).

## Что он делает и чего не делает

Читает главы, **которые ваш аккаунт уже может открыть**, и собирает из них EPUB
с обложкой и оглавлением.

- Бесплатные главы не требуют аккаунта вообще.
- Для VIP-глав нужно быть залогиненным **и владеть покупкой**. Вход происходит
  в настоящем браузере, который вы открываете и заполняете сами; ваш пароль
  инструмент не видит и не хранит.
- Главы, которые вы не покупали, помечаются как `paywalled`, попадают в отчёт
  и в EPUB не включаются. Заглушками они не заполняются.

Это не обход пейвола, и никаких технических средств защиты инструмент не
трогает. Хотите книгу — купите её: команда `fetch` печатает стоимость
VIP-части конкретного романа заранее.

> **Готовые файлы держите при себе.** JJWXC встраивает в текст VIP-глав
> водяные знаки, привязанные к купившему аккаунту. Файл, которым вы
> поделитесь, указывает на вас.

## Требования

Python 3.9+ и система, куда Playwright сможет поставить Chromium. Проверено на
Python 3.14 / Windows 11 и Python 3.10.

```bash
pip install -r requirements.txt
```

```bash
python -m playwright install chromium
```

## Использование

`novelid` виден в адресе страницы романа:
`jjwxc.net/onebook.php?novelid=`**`1234567`**.

### 1. Скачивание

```bash
python jjwxc_dl.py fetch 1234567
```

```
某本书 - 某作者
305 chapters: 21 free (65,284 chars), 284 VIP (1,071,596 chars)
VIP portion costs roughly 5358 coins (~53.6 CNY) at the standard 5 fen/1k rate
305 chapters to fetch

[1/305] 第一章 (free) ... ok, 3021 chars
[22/305] 第二十二章 (VIP) ... paywalled
```

Каждая глава сохраняется в отдельный JSON-чекпойнт, поэтому Ctrl+C безопасен:
повторный запуск той же команды пропускает уже полученное и повторяет только
то, что не удалось.

### 2. Вход в аккаунт (разово, для VIP-глав)

```bash
python jjwxc_dl.py login
```

Откроется браузер на jjwxc.net. Залогиньтесь сами, затем нажмите Enter в
консоли. Сессия останется в `.jjwxc-profile/` рядом со скриптом и будет
переиспользована последующими запусками `fetch`. Не запускайте две копии
инструмента на одном профиле — Chromium блокирует его под один процесс.

### 3. Сборка EPUB

```bash
python jjwxc_dl.py build 1234567
```

Пишет `downloads/<novelid>/<название>.epub` и перечисляет главы, которых в нём
нет.

### Параметры

| Флаг | По умолчанию | Примечание |
| --- | --- | --- |
| `--delay` | `2.0` | Базовая пауза между главами; фактическая — от `delay` до `2×delay`. |
| `--timeout` | `20.0` | Таймаут на страницу, в секундах. Поднимите на медленном канале. |
| `--retries` | `3` | Попыток на главу, с наращиванием паузы. |
| `--headless` | выкл. | Скрыть браузер. На первом запуске лучше оставить выключенным. |
| `--out` | `downloads` | Куда складывать чекпойнты и EPUB. |
| `--profile` | `.jjwxc-profile` | Профиль браузера с вашей сессией. |

**Не занижайте `--delay`.** Триста с лишним запросов подряд на полной скорости —
самый быстрый способ получить ограничение по частоте, и это невежливо по
отношению к сайту, которому вы платите.

## Структура файлов

```
downloads/<novelid>/
├─ meta.json              название, автор
├─ cover.jpg
├─ <название>.epub
└─ chapters/
   └─ 0001.json           index, title, url, vip, words, text, status
```

`status` принимает значения `ok`, `paywalled`, `error`.

## Разбор проблем

**Купленные главы возвращаются как `paywalled`** — сессия не подхватилась.
Перезапустите `login` и убедитесь, что в открывшемся окне вы действительно
залогинены. Проверьте, что `fetch` и `login` используют один и тот же
`--profile`.

**Много `error`** — поднимите `--timeout`, затем `--delay`. Повторный запуск
пробует только неудавшиеся главы.

**Ошибка на всех главах сразу** — скорее всего изменилась вёрстка и селектор
`div.noveltext` больше не подходит. Запустите без `--headless`, посмотрите на
страницу и откройте issue с описанием.

**`UnicodeEncodeError` при печати названий** — не должно происходить,
инструмент принудительно включает UTF-8 на своих потоках. Если всё же
случилось, сообщите вашу ОС и консоль.

## Благодарности

Переписано с [tracywong117/jjwxc-downloader](https://github.com/tracywong117/jjwxc-downloader),
где заложен сам подход: разбирать страницу оглавления для списка глав, а текст
главы брать из того дочернего элемента `div.noveltext`, в котором больше всего
текста.

Заметные изменения:

- **Playwright вместо Selenium.** Persistent context означает, что логинишься
  один раз и VIP-главы становятся достижимы в принципе; версию
  `chromedriver.exe` подгонять не нужно; локаторы ждут сами.
- **VIP-строки разбираются.** У платных глав нет `href` — адрес лежит в `rel=`
  и ведёт на `my.jjwxc.net`, а клик обрабатывается JS. Поиск только по `href`
  молча пропускает все платные главы книги.
- **Обход строк таблицы вместо `zip()`** двух независимых результатов XPath:
  второй вариант перепутывает названия и адреса, едва списки разойдутся.
- **Возобновляемость.** Чекпойнт на главу в отдельном JSON вместо дописывания
  в один растущий `.txt`, который при повторном запуске дублировал всю книгу.
- **Неоплаченные главы отслеживаются**, а не пишутся в книгу заглушкой.
- **Валидный EPUB.** Текст экранируется перед вставкой в XHTML, поэтому
  случайные `<` или `&` больше не ломают файл. Проставлены метаданные языка.
- **Число знаков по главам** читается из оглавления — отсюда и оценка стоимости.
- UTF-8 принудительно включён на stdout/stderr, чтобы консоль не в UTF-8 не
  обрывала длинную загрузку.
